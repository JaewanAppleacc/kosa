- 실제 LLM 경로로 생성됨: 26/27
- Fallback(base_question)으로 넘어감: 1/27
- Trait Label 노출 발견: 0건

- Target 길이 이상치(다른 선택지 평균보다 10자 이상 김) 발견: 3건

'문장 자연스러움 검토'/'인접 Trait 혼동 가능성'/'사람 검토 상태'는 항상 TBD다 — 이 스크립트가 자동으로 채우지 않는다(§12 자동 검사는 검토 후보 표시 용도). Target 길이 이상치도 '편향 없음'을 확정하는 게 아니라 검토 후보 표시일 뿐이다.

재요청 시 LLM 호출이 늘지 않는지(멱등성)는 이 스크립트가 아니라 `tests/test_v2_direct_probe.py`의 FakeLLM 기반 단위 테스트로 검증한다 — 멱등성은 코드 경로의 성질이라 실제 LLM 백엔드와 무관하고, 반복 검증에 실제 요금이 드는 네트워크 호출을 쓸 이유가 없다.
