# 6. 재검토 트리거

근거는 조건이 바뀌면 무효가 된다. 아래가 발생하면 해당 결정을 다시 본다.

| 트리거 | 다시 볼 결정 |
|---|---|
| 대학알리미 API Key 발급 | 2번 데이터 규모 전체, `schl_id`·`department_id` 재생성 (3-3) |
| 전국 수집 후 `REVIEW_REQUIRED` 30% 초과 | Alias 표 확충 (1-2). 문턱 완화가 아니다 |
| 실제 대학 홈페이지 수집 시작 | RAG 커버리지 지표를 질의 유형 → 학과별 항목 충족률로 (2-1), 샘플 문서 제거 (3-2) |
| 입결 출처 확정 | 컷 점수 채우고 `verified` 승격 (3-1) |
| 코퍼스가 수천 Chunk로 증가 | 메모리 `VectorIndex` → pgvector (5-5) |
| 형태소 분석기 도입 | `tokenize()` 교체, 4-2 바닥선 재측정 |
| Alias 표에 새 과목 추가 | 4-1 재측정 — 새 과목이 기존 과목과 0.82 이상으로 겹칠 수 있다 |
| Trait 30개 초과 | 1-1의 "규칙으로 판정" 전제 재검토 |
